# 歌枠時間軸

一個不需要 YouTube API、後端或登入的 Chrome Side Panel 擴充功能。它能從目前影片的說明欄、已載入留言或手動貼上的文字建立 Setlist，並在下一個時間戳前循環播放歌曲。

## 載入方式

1. 開啟 `chrome://extensions`。
2. 啟用右上角的「開發人員模式」。
3. 選擇「載入未封裝項目」，指定此資料夾。
4. 開啟任一 YouTube 影片，再點擊工具列的「歌枠時間軸」。

若擴充功能是在 YouTube 分頁已經開啟後才載入，請先重新整理 YouTube 分頁，讓內容腳本生效。

## 使用方式

- 按「掃描目前頁面」解析影片說明欄與已經捲動載入的留言。
- 若掃描不到留言，按「貼上時間軸」直接貼入整則 Setlist 留言。
- 點歌曲即可跳轉並循環至下一個歌曲或段落時間。
- 使用編輯按鈕將項目改為歌曲、段落、註記或隱藏，並可修正標題與起訖時間。
- 每支影片以 YouTube `videoId` 儲存在 `chrome.storage.local`；再次開啟時直接載入。
- 設定頁可匯出或匯入 JSON 備份。

## 隱私

擴充功能沒有後端，也不呼叫 YouTube Data API。掃描到的文字、使用者修正與備份資料只會保存在瀏覽器本機，不會傳送到外部服務。
